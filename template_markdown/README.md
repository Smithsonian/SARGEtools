# SARGE Markdown 

The SARGEtools template_markdown directory includes all code, data, and functions needed to run a markdown summary of SARGE data. These materials are intentionally designed to be modular and reproducible for other applications. The example pdf and code walk users through how to configure data for easy use with SARGEtools functions. 

To modify these files for your own system, users will need to updated the files in `./configure_data` folder to include the correct file paths, column names, and colors for your application. Then, run `SARGEtools_markdown.Rmd` with updated start and end time points to view real-time data. 

This markdown can be used to create pdf summaries of deployments, look at short windows of data, and aid in the development of custom workflows.
